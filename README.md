# Can't see

windowsとLinuxの両方でプレイが可能です。



## インストール方法

1.このページの右側にある**Releases**を開きます。

2.プレイしたいバージョンのzipファイルをインストールして、解凍（展開）してください。



## 起動方法

### windowsの場合

1.解凍したファイルのwindowsフォルダを開きます。

2.cant_see.exeファイルをダブルクリックしてゲームを起動してください。

(windowsの保護機能が起動する可能性がございます。その場合の起動方法につきましては**ヘルプ**をご確認ください)

### Linuxの場合
1.ターミナルを起動し、解凍したフォルダに移動します。

（フォルダへの移動方法がわからない場合は**ヘルプ**をご確認ください）

2.以下のコマンドをを順に実行して、ゲームを起動してください。
  
  chmod +x cant_see
  
  ./cant_see



## ヘルプ

"Linuxでのフォルダへの移動方法がわからない場合"

 1.cant_seeフォルダをhome（ホームディレクトリ）へ移動させてください。
 
 2.ターミナルに以下のコマンドを入力すると、フォルダへ移動することができます。
 
   cd ~/cant_see
   
"windowsの保護機能が起動する場合"

 1.詳細情報をクリックします。
 
 2.実行をクリックしてください。
