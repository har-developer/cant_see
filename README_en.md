# Can't see

Playable on both Windows and Linux.



## Installation

1. Open **Releases** on the right side of this page.

2. Download the zip file for the version you want to play, and extract (unzip) it.



## How to Launch

### For Windows

1. Open the extracted folder.

2. Double-click the 'cant_see.exe' file to launch the game.

(Windows Defender protection may appear. If so, please check the **Help** section for instructions.)

### For Linux

1. Open your terminal and navigate to the extracted folder.

(If you do not know how to navigate to the folder, please check the **Help** section.)

2. Run the following commands in order to launch the game:
  
  chmod +x cant_see
  
  ./cant_see



## Help

"If you don't know how to navigate to the folder on Linux"

 1. Move the 'cant_see' folder to your 'home' (home directory).
 
 2. Enter the following command in the terminal to navigate to the folder:
 
    cd ~/cant_see
   
"If Windows protection appears"

 1. Click "More info".
 
 2. Click "Run anyway".
